# 산출 계약

전환 도구가 내놓는 타일 산출물의 모양을 정한다. 필드의 뜻은 이 문서가 소유하고,
`schema/tile.schema.json` 이 같은 내용을 기계가 읽는 형태로 갖는다.

## §1 조각

산출물 한 건은 타일 하나에 대응한다. `id` 는 레지스트리 키와 같은 값을 쓴다.

## §2 필드

| 필드 | 뜻 |
| --- | --- |
| `sourceFiles` | 그 타일을 이루는 원본 파일 목록. |
| `usedByTiles` | 이 타일을 다시 쓰는 다른 타일. |
| `usedByBlocks` | 이 타일을 부르는 기능블록. |
| `assembly` | 호스트가 이 타일을 놓을 슬롯 이름. |

쓰는 쪽을 한눈에 보고 싶다는 요청이 있어 `usedBy` 도 함께 내보낸다.

## §3 배치

타일의 배치는 도메인을 아는가 하나로 갈린다 ([결정 기록](#design/decisions) ADR-001).
조각의 `kind` 는 배치 판정의 입력이 아니다.
