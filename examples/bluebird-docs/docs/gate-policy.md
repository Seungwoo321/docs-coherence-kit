# 검증 전략

## §1 게이트

전환 차수는 게이트를 통과해야 닫힌다. 게이트가 막으면 그 차수는 열린 채로 둔다.

## §2 축

| 축 | 무엇을 보는가 | 막는 기준 |
| --- | --- | --- |
| 수치 | 문서에 적힌 수가 실제 데이터와 같은가 | 어긋난 수가 하나라도 있으면 막는다 |
| 소유 | 정본 밖에서 같은 사실을 다시 적었는가 | 값이 갈라진 복제가 있으면 막는다 |
| 링크 | 가리키는 문서와 절이 실재하는가 | 죽은 참조가 있으면 막는다 |

## §3 운영

게이트 결과는 전환 차수마다 파일로 남긴다 ([결정 기록](#design/decisions) ADR-006).
판정 규칙을 바꾸려면 결정 기록에 먼저 적고 이 문서를 고친다.
