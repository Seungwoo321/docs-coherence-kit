# 현행 실측

전환을 시작하기 전의 포털 상태를 숫자로 적는다. 이 문서의 수치가 정본이고, 다른 문서는
숫자를 다시 적는 대신 이 문서를 링크로 인용한다.

## §1 세는 범위

세는 대상은 `bluebird-portal-web` 레포의 `portal` 앱 하나다. 실험용 브랜치와 사내 도구는
세지 않는다. 실제 수는 `data/tiles.json` 과 `data/deploy-units.json` 이 갖고 있고, 이 문서는
그 두 파일을 읽어 적는다.

## §2 타일

레지스트리에 올라 있는 등록 타일 46 개를 전환 차수로 가른다.

### §2.1 차수별 분포

| 구분 | 타일 수 |
| --- | ---: |
| 1차 전환 | 26 |
| 2차 전환 | 14 |
| 이관 제외 | 8 |
| 합계 | 46 |

## §3 배포단위

지금은 배포단위 6 개가 한 파이프라인에서 함께 나간다. 타일이 아무리 늘어도 배포는
이 여섯 묶음으로만 이뤄진다.
