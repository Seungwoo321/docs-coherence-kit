# 용어집

Bluebird 회의실 예약 포털의 설계 문서가 같은 낱말을 같은 뜻으로 쓰기 위한 정본이다.
낱말의 뜻은 이 문서가 소유한다 ([결정 기록](#design/decisions) ADR-002).

## §1 코드 구조

| 낱말 | 뜻 |
| --- | --- |
| 기능블록 | 예약 흐름의 한 단계를 담는 코드 묶음. 화면에 직접 붙지 않는다. |
| 타일 | 포털 화면 한 칸을 채우는 조립 단위. 기능블록을 골라 담아 만든다. |
| 슬롯 | 호스트 화면에서 타일 하나가 들어갈 자리. |

## §2 실행 구조

| 낱말 | 뜻 |
| --- | --- |
| 호스트 | 타일을 받아 화면에 배치하는 실행 주체. 화면 내용은 갖지 않는다. |
| 배포단위 | 따로 빌드해 따로 올리는 묶음. 타일 여럿이 한 배포단위에 들어갈 수 있다. |
| 전환 | 한 덩어리로 뭉친 포털을 배포단위로 갈라내는 작업. |
