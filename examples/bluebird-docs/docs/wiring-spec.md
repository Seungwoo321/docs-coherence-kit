# 조립 계약

호스트가 타일을 받아 화면에 놓는 절차를 정한다.

## §1 슬롯

호스트 화면은 슬롯 여섯 자리로 나뉜다. 슬롯 하나에는 타일 하나만 들어가고, 빈 슬롯은
빈 채로 그린다.

## §2 주입

타일은 자기가 필요한 데이터를 직접 부르지 않고, 호스트가 넘긴 값만 읽는다.
예약 데이터를 실제로 부르는 일은 `booking-core` 안에서만 한다.
넘길 값의 모양은 [산출 계약](field-spec.md) §2 가 정한다.

## §3 실패 처리

타일 하나가 뜨지 않아도 나머지 슬롯은 그대로 그린다. 화면 전체를 내리지 않는다.
