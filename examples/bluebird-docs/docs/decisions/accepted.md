# 채택된 결정

전환 과정에서 굳힌 결정을 한곳에 모은다. 새 결정은 아래에 덧붙이고, 이미 적힌 글은
고치지 않는다 — 그래서 이 문서는 동결 대상이다.

## ADR-001 타일 배치는 도메인 지식 유무로 가른다

- **상태** accepted
- **맥락** 처음에는 조각의 `kind` 로 배치를 갈랐는데, 같은 값이 서로 다른 슬롯으로 갔다.
- **결정** 배치는 도메인을 아는가 하나로 가른다. [산출 계약](#design/field-spec) §3 이 이 판정축을 인용한다.
- **결과** 배치 기준이 한 문서로 모인다.

## ADR-002 낱말의 뜻은 용어집이 소유한다

- **상태** accepted
- **결정** 같은 낱말이 문서마다 다른 뜻으로 쓰이지 않도록 [용어집](#design/glossary) 이 뜻을 소유한다.

## ADR-003 전환 차수는 두 번으로 끊는다

- **상태** accepted
- **결정** 전환은 1차·2차 두 차수로 끊는다. 차수별 범위는 [전환 계획](#design/phase-notes) 이 갖는다.

## ADR-004 공유 패키지는 표시 요소만 갖는다

- **상태** accepted
- **결정** 공유 패키지에는 예약 규칙을 두지 않는다. 표시 요소만 남긴다.

## ADR-005 게이트 결과는 콘솔로만 본다

- **상태** superseded by ADR-006
- **결정** 게이트 결과는 콘솔 출력으로만 확인한다.

## ADR-006 게이트 결과를 파일로 남긴다

- **상태** accepted
- **결정** 게이트 결과는 전환 차수마다 파일로 남긴다.
