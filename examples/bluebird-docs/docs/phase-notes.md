# 전환 계획

## §1 원칙

한 번에 한 배포단위씩 갈라낸다. 전환 중에도 포털은 계속 뜨고, 되돌릴 자리를 항상 남긴다.

## §2 범위

1차 전환 대상은 31 개로 잡았다. 나머지는 다음 분기로 미룬다.
슬롯 주입 규칙은 [조립 계약](wiring-spec.md#슬롯-주입-규칙) 에 적어 뒀다.

## §3 순서

전환 순서는 의존 그래프를 따른다. 공유 패키지에 기대는 타일이 뒤로 간다.
2차 전환 14 개는 1차가 끝난 뒤에 손댄다 ([현행 실측](#design/scope-table) §2).

## §4 게이트

각 차수는 [검증 전략](gate-policy.md) §9 의 게이트를 통과해야 닫힌다.
